# {{TITLE}}

Rust project on a pinned toolchain, managed with [codenv](https://github.com/Tijani127/codenv).

## Getting started

```sh
codenv install
codenv shell
```

## Scripts

```sh
codenv run build
codenv run test
codenv run lint
codenv run fmt
```

Commit `codenv.json` and `codenv.lock.json`; ignore `.codenv/` and `target/`.
